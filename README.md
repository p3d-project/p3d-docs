# P3D Docs

P3D Docs is the official documentation website The P3D  Project. It serves as the main distribution point for all project docs, including team setup & codebase references.

Engineered for high performance and long-term maintainability, P3D Docs is built on the Astro framework with React components and Tailwind CSS to leverage fast static-site generation and responsive, utility-driven design.
